# 🌱 Agribot – AI-Powered Agricultural Robot

## 📌 Project Overview

Agribot is an agricultural robotics project designed to automate fruit harvesting and improve efficiency in farming operations. It combines a robotic arm, an Arduino-based control system, and a wheeled mobile platform to support precise and efficient agricultural tasks.

## 🎯 Objectives

* Automate fruit harvesting using a robotic arm.
* Improve precision in robotic manipulation.
* Enable mobility across agricultural fields.
* Develop a cost-effective agricultural automation system.

## ⚙️ Key Features

* **4-DOF Robotic Arm:** Enables controlled movement for fruit-picking operations.
* **Arduino-Based Control:** Uses Arduino Uno R3 to coordinate robotic arm movements.
* **Embedded Programming:** Implements hardware control using C.
* **Wheeled Mobile Platform:** Supports movement across agricultural terrain.
* **Precision Control:** Designed to achieve accurate robotic arm positioning.

## 🛠️ Technologies Used

* Arduino Uno R3
* Embedded C
* Robotics and Automation
* Robotic Manipulation
* Embedded Systems

## 🏗️ System Components

1. **Arduino Uno R3:** Acts as the primary controller for robotic operations.
2. **Robotic Arm:** A 4-degree-of-freedom (4-DOF) mechanism for fruit harvesting.
3. **Mobile Platform:** A wheeled base designed to support movement across agricultural fields.
4. **Control System:** Coordinates arm movements and platform operations.

## 🚀 Working Principle

1. The mobile platform moves to the required location.
2. The robotic arm is positioned toward the target fruit.
3. The Arduino-based control system coordinates the arm's movements.
4. The robotic arm performs the harvesting operation.
5. The process can be repeated for other target fruits.

## 📊 Project Outcomes

* Developed a prototype for agricultural harvesting automation.
* Integrated embedded control with robotic manipulation.
* Designed a mobile platform for agricultural applications.
* Targeted a robotic arm reach of up to 180 cm and approximately 99% positioning accuracy during testing.

Agribot demonstrates the application of embedded systems and robotics in agriculture. By integrating an Arduino-controlled robotic arm with a mobile platform, the project explores an affordable approach to automating harvesting operations and reducing manual effort.
